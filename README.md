## 🔥 Featured Projects

### 01 — AI Resume Screening & HR Document Q&A

> **Production-style RAG system for document-grounded HR question answering**

**Stack:**  
`Python` `FastAPI` `FAISS` `BM25` `LangChain` `Ollama` `Llama 3` `Sentence Transformers` `Cross-Encoder` `PyMuPDF` `Groq` `OpenAI`

#### What I built

- 🔎 Combined **BM25 lexical retrieval + FAISS vector retrieval** for hybrid search.
- 🎯 Added **cross-encoder reranking** using `ms-marco-MiniLM-L-6-v2`.
- 🧾 Designed a citation-first answering pipeline with **source file and page-number references**.
- 🛡️ Constrained LLM responses to retrieved document content.
- 🔁 Implemented automatic LLM failover between **Groq Llama 3.3 70B** and **OpenAI GPT-4o-mini**.
- ⚡ Built a **FastAPI backend** for service-oriented deployment.
- 🖥️ Built a **Streamlit PDF upload interface** with live in-memory indexing.
- 💾 Added a persisted FAISS index for faster startup.
- 📈 Created an automated evaluation harness using a golden test dataset.

**Engineering focus:** `Retrieval Quality` → `Reranking` → `Grounded Generation` → `Citations` → `Evaluation` → `Deployment`

### 02 — Insurance Charges Prediction

> **End-to-end Machine Learning pipeline for insurance premium prediction**

**Stack:**  
`Python` `Pandas` `NumPy` `Scikit-learn` `Statsmodels` `Streamlit` `Joblib`

#### Highlights

- 📈 Built Linear Regression and Gradient Boosting models.
- 🏆 Achieved **R² = 0.83** on held-out data.
- 🧹 Applied skew-aware data cleaning and IQR-based outlier treatment.
- 🔬 Used **VIF-based multicollinearity elimination**.
- 📊 Applied **t-test and ANOVA** for feature validation.
- 🎯 Reduced 10+ raw features to **6 statistically significant predictors**.
- 📐 Validated assumptions using residual analysis and Q-Q plots.
- 📉 Created actual-vs-predicted regression analysis.
- 🚀 Deployed the trained model using **Joblib + Streamlit**.
